ในการพัฒนาระบบครั้งนี้ ได้ดำเนินการเพิ่มเติมใน 3 ส่วนหลัก ได้แก่ **Change Password**, **Comment Ownership** และ **Comment Emoji Reactions** เพื่อเพิ่มความปลอดภัย ความถูกต้องในการจัดการข้อมูล และประสบการณ์การใช้งานของผู้ใช้งาน

**ส่วนที่ 1: Change Password**

ได้พัฒนาระบบสำหรับเปลี่ยนรหัสผ่าน โดยสร้างไฟล์ `app/api/change-password/route.ts` เพื่อรองรับ POST endpoint สำหรับการเปลี่ยนรหัสผ่านให้เป็นไปตาม Requirement ที่กำหนด

นอกจากนี้ยังเพิ่ม `changePasswordSchema` ในไฟล์ `lib/schemas.ts` เพื่อใช้ตรวจสอบความถูกต้องของข้อมูลที่ผู้ใช้ส่งเข้ามา

และเพิ่มฟังก์ชัน `findUserById` และ `updateUserPassword` ในไฟล์ `lib/users.ts` เพื่อใช้ค้นหาข้อมูลผู้ใช้และอัปเดตรหัสผ่านใหม่ในฐานข้อมูล

**ส่วนที่ 2: Comment Ownership**

ได้เพิ่มระบบจัดการความคิดเห็นและกำหนดสิทธิ์ความเป็นเจ้าของความคิดเห็น โดยเพิ่ม `Comment model` พร้อม `authorId` ในไฟล์ `prisma/schema.prisma` เพื่อระบุว่าความคิดเห็นแต่ละรายการเป็นของผู้ใช้คนใด

จากนั้นเพิ่ม `commentSchema` และ `commentUpdateSchema` ในไฟล์ `lib/schemas.ts` เพื่อใช้ตรวจสอบข้อมูลในการสร้างและแก้ไขความคิดเห็น

สร้างไฟล์ `lib/commentService.ts` สำหรับจัดการ CRUD ของความคิดเห็น พร้อมเพิ่มการ Sanitize ข้อมูลในระดับ L3 และตรวจสอบสิทธิ์ผู้ใช้งานในระดับ L4 เพื่อป้องกันไม่ให้ผู้ใช้ที่ไม่มีสิทธิ์สามารถแก้ไขหรือลบความคิดเห็นของผู้อื่นได้ หากไม่ใช่เจ้าของความคิดเห็น ระบบจะส่งสถานะ **403 Forbidden**

สำหรับ API ของความคิดเห็น ได้สร้าง `app/api/comments/route.ts` เพื่อรองรับการเรียกดูและเพิ่มความคิดเห็นผ่าน GET และ POST

และสร้าง `app/api/comments/[id]/route.ts` เพื่อรองรับการแก้ไขและลบความคิดเห็นผ่าน PATCH และ DELETE โดยมีการตรวจสอบ Ownership ก่อนดำเนินการ หากผู้ใช้งานไม่ใช่เจ้าของความคิดเห็น ระบบจะปฏิเสธการดำเนินการด้วยสถานะ **403 Forbidden**

**ส่วนที่ 3: Comment Emoji Reactions (Schema, Model/Service/Controller, และ UI)**

ได้พัฒนาระบบแสดงความรู้สึก (Emoji Reaction) ให้กับแต่ละความคิดเห็นตามสถาปัตยกรรมแบบแบ่งชั้น (Layered Architecture):

1. **Database Schema:** เพิ่ม `CommentReaction model` ในไฟล์ `prisma/schema.prisma` ประกอบด้วย `commentId`, `userId`, `emoji` และสร้าง Unique Index `@@unique([commentId, userId, emoji])` เพื่อจำกัดให้ผู้ใช้ 1 คนสามารถแสดงความรู้สึกแต่ละอีโมจิในคอมเมนต์เดียวกันได้เพียง 1 ครั้ง และรองรับการ Toggle เปิด-ปิด
2. **API Architecture (Model / Service / Controller):**
   - **Model Layer:** สร้างไฟล์ `lib/reactions.ts` สำหรับจัดการคำสั่ง SQL / Prisma Queries ในการค้นหา เพิ่ม และลบ Reaction (`findReaction`, `addReaction`, `deleteReaction`)
   - **Service Layer:** เพิ่มฟังก์ชัน `toggleCommentReaction` ในไฟล์ `lib/commentService.ts` พร้อมเพิ่ม `reactionSchema` ใน `lib/schemas.ts` เพื่อ Validate ข้อมูลด้วย Zod และจัดการสลับสถานะ (ถ้าเคยกดแล้วจะลบออก ถ้ายังไม่เคยกดจะเพิ่มใหม่)
   - **Controller Layer:** สร้างไฟล์ `app/api/comments/[id]/reactions/route.ts` รองรับ POST endpoint สำหรับรับ Request โดยตรวจสอบ `userId` จาก Session Cookie ป้องกันการกดสแปมจากบุคคลภายนอก หากยังไม่เข้าสู่ระบบจะส่งสถานะ **401 Unauthorized**
3. **UI Layer (ปุ่ม React + แสดงจำนวน):**
   - ปรับปรุงคอมโพเนนต์ `components/CommentSection.tsx` โดยเพิ่มแถบปุ่มแสดงความรู้สึกด้วยอีโมจิ (👍, ❤️, 😂, 🎉, 🚀) ใต้แต่ละความคิดเห็น
   - แสดงตัวเลขนับจำนวนผู้กดของแต่ละอีโมจิ
   - แสดงสถานะ Active (ไฮไลต์สีฟ้า) บนอีโมจิที่ผู้ใช้งานปัจจุบันเคยกดไว้ และรองรับการกดเพื่อสลับสถานะ (Toggle) ได้อย่างราบรื่น

โดยการพัฒนาทั้งสามส่วนนี้ช่วยเพิ่มความสมบูรณ์ ความปลอดภัย และการมีปฏิสัมพันธ์ของผู้ใช้งานภายในระบบอย่างครบถ้วน
